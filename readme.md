
### Only for 2.22, which is the RC branch for now. Otherwise you would have no radar completely.
I tried to solo Air Control. That... was not fun. I ended up modding the Mi-35 from Aegis heavily, which became this.

# Armor
Now ‘on par’ with base game choppers. Armored side canopy. 30mm armor around cockpits, engine and main rotor hub. 20mm around inner main rotor section, cabin floor and tail rotor. Rest of the airframe has 12mm armor.
# Avionics
Radar now moved to a pylon mounted mast sensor. A MKII sensor is available with enhanced radar, datalink and passive radar capability

Base aircraft also has datalink, range to 8km.

HMD Added. Range to target is always shows, increase precision to 2 decimal places.

Slingloading camera, controllable to assist landing.

Automatic countermeasure system. Select the type, burst and interval. NOTE: selected turret needs to be occupied to work.

Designate multiple laser targets from the map. Hit all targets in a single pass!

# Cargo
4 seats are now FFV

Crammed in 3 more passengers

Slingloading mass limit increased to 4000kg

Build in paradrop script
# Weapon
Main gun now based on 20mm Autocannon from AWC Lynx. Rate of fire increased to 900 rpm. Ammo increased to 840 rounds total. AP round has a slight damage bump and no splash damage

Wingtip pylons for missiles. 

New Scalpel NLOS variant, now datalink enabled and with limited anti-air capability.

More supported weapons on pylons. Proxy position adjusted to fit jet weapons better.

Weapon groups changed to
1.	Cannon and machine gun
2.	Air to Air missiles
3.	Air to ground missiles
4.	Bombs, rockets, Laser Designators
# Advanced flight model
Changed from Mi-48 to RHS Mi-24
